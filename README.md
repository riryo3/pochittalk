# ぽちっと通話 (α版)

ボタンを押している間だけ話せる、トランシーバー風のグループ通話です。
登録もログインも要らず、ブラウザで開くだけで使えます。部屋は公開で、知らない人にも声が聞こえます。

個人が作ったα版です。動作や安全性の保証はありません。自己責任で使ってください。

- Web 版: Cloudflare Workers の単一ファイル（`worker.js`）で動きます
- iPhone 版: [`ios/`](ios/README.md)（Swift / SwiftUI、α）
- Android 版: [`android/`](android/README.md)（Kotlin、α）
- Web 版・iPhone 版・Android 版は、同じ部屋で相互に通話できます（アプリは、まだ配布前で、実機で試している段階です）

## 特長

- **押している間だけ話せる**。離すと聞く側に戻ります。VOX（声で自動送信）もあります
- **つながるのが速い**。接続の準備を、必要になってから作る方式にしています（下の「仕組み」）
- **部屋の名前は英数字 8 桁**（a〜z と 0〜9。表示は `XXXX·XXXX`）。`kawaii07` のような名前も付けられます。16 進だけの昔の番号も、そのまま使えます
- 部屋の一覧（ダイヤル）、招待 URL と QR、話題のタグ、入退室の確認、新しい部屋の音（設定でオン）
- 診断画面で、誰と何本つながっているか、経路、遅延、音が流れているかを見られます。つながっていない人は、赤いチップで出ます
- 「おうむ返しボット」の部屋（`2236·0679`）で、1 人でも、音が出ているかを確かめられます。ボットはログを残しますが、話した内容（声）は覚えていません

## 仕組み

- 音声は WebRTC の P2P です。通話の経路は、中継サーバー（Cloudflare TURN）を通すものに限っているので、相手に自分の IP アドレスは見えません
- 「同じ部屋にいる人を見つける」仲介には、[Trystero](https://github.com/dmotz/trystero)（0.25.4、Nostr 方式）を使い、`worker.js` から配信します
- 部屋の一覧は、Nostr の在室通知で共有します（人数、ハンドルネーム、話題）
- Trystero は、部屋に入るとき、接続の準備（オファー）を先に 20 個作る作りでした。これを 0 にして、誰かが来たときに、その相手のぶんだけ作ります。端末が多いときの遅さの、主な原因でした
- 通信の記録は、標準では端末に保存しません。設定でオンにしたときだけ、直近の最大 300 行を端末に保存します（名前の前に 💾 が付きます）
- 詳しいプライバシー情報は、アプリ内の「このアプリについて」にあります

## デプロイ（Web 版）

1. Cloudflare のダッシュボードで Worker を作り、「コードを編集」に `worker.js` の全文を貼って Deploy します
2. HTTPS の URL を開くだけで使えます（マイクは HTTPS が必須です）
3. 中継サーバー（TURN）を使うには、Worker の「変数とシークレット」に、Cloudflare の TURN の鍵を設定します
   - `TURN_KEY_ID`（テキスト）と `TURN_API_TOKEN`（**シークレット**）
   - **鍵を `worker.js` に直接書かないでください。GitHub に公開されます**
   - 未設定のときは、中継なしで、直接の接続（STUN）で動きます。環境によってはつながらないことがあります

人数の上限は、`worker.js` の `MAX_ROOM`（既定は 8）で変えられます。

## 部屋番号について（互換性）

部屋番号は、a〜z と 0〜9 の 8 桁です。英字を含む部屋は、この対応を入れる前の古い版（Web・アプリ）からは、一覧に見えず、入れません。数字と a〜f だけの部屋は、古い版からも使えます。
